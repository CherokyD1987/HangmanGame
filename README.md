# Висельница (Hangman)

Консольная игра «Виселица» на Java. Компьютер загадывает слово из русского
словаря, игрок называет буквы по одной. Это учебный проект: первый из серии
проектов курса по Java backend.

## Правила

- Компьютер случайно выбирает слово (от 5 букв) из словаря на ~5000 слов.
- Вы называете буквы по одной, только русские (`ё` считается отдельной буквой).
- Если буква есть в слове, она открывается.
- Если буквы нет, на виселице дорисовывается новая часть.
- После 6 ошибок вы проигрываете, если слово открыто целиком, выигрываете.
- Повторно названная буква ошибкой не считается.

## Требования

- JDK 25
- Maven (необязательно, проект собирается и без него)

## Запуск

**В IntelliJ IDEA:** откройте проект, запустите класс `Main`.
Если вместо русских букв видны квадраты, добавьте в VM options запуска:
`-Dfile.encoding=UTF-8 -Dstdout.encoding=UTF-8`

**Из терминала** (из корня проекта, так как путь к словарю относительный):

```
javac -encoding UTF-8 -d out src/main/java/*.java
java -Dfile.encoding=UTF-8 -Dstdout.encoding=UTF-8 -cp out Main
```

## Структура проекта

| Класс | Ответственность |
|-------|-----------------|
| `Main` | Меню и игровой цикл, вывод в консоль |
| `GameRound` | Правила одного раунда: слово, названные буквы, ошибки, победа и поражение |
| `RandomWord` | Загрузка словаря из файла и выбор случайного слова |
| `ConsoleInput` | Ввод одной русской буквы с проверкой |
| `GallowsState` | Enum со всеми состояниями виселицы (ASCII-рисунки) |
| `GameMenu` | Enum с пунктами меню и клавишами выбора |

Словарь лежит в `src/main/resources/words_5000_ru.txt`.

- Покрыть `GameRound` тестами
